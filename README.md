# 코레일 취소표 예매 보조 도구

`.omc/plans/korail-cancellation-catcher.md`에 정리된 계획대로 만든 도구입니다.
**모든 조회는 "② 지금 1회 확인하기" 버튼을 누를 때만 딱 1번 실행됩니다. 프로그램이 스스로 반복하지 않습니다.**
결제(최종 구매)는 절대 자동으로 하지 않습니다 — 좌석을 임시로 잡아두기(예약)까지만 자동이고, 결제는 알림을 받은 뒤 직접 진행하세요.

## 처음 한 번만 하는 준비

### 1. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 텔레그램 알림 설정
1. 텔레그램 앱에서 `@BotFather` 검색 → `/newbot` 입력해서 봇 생성 → 토큰(긴 문자열) 복사
2. 만든 봇과 대화창을 열고 아무 메시지나 보내기 (예: "안녕")
3. 브라우저에서 `https://api.telegram.org/bot<위에서 복사한 토큰>/getUpdates` 접속 → `"chat":{"id":숫자...` 부분에서 숫자가 chat id
4. `.env.example` 파일을 복사해서 `.env`로 이름 바꾸고, 토큰과 chat id를 입력

### 3. 실행
```bash
python src/main.py
```
처음 실행 시 코레일 로그인 정보(회원번호/이메일/전화번호 + 비밀번호)를 물어보는 창이 뜹니다.
한 번 입력하면 Windows 자격 증명 관리자에 암호화되어 저장되고, 다음부터는 자동으로 로그인됩니다.

## 사용 방법

1. **① 로그인 확인 / 조건 불러오기** 클릭 → 코레일 로그인 상태 확인, 화면에 7개 목표 열차 목록이 뜸
2. 생각날 때마다 **② 지금 1회 확인하기** 클릭 → 그 순간 딱 1번, 7개 열차 모두 확인
   - 매진 → 화면에 "매진" 표시
   - 좌석 있음 → 자동으로 임시 예약 + 텔레그램 알림 → **직접 코레일 앱/사이트에서 결제** (제한시간 있음, 보통 10~20분)
3. 이미 확보된 열차는 자동으로 다음 확인부터 제외됩니다.

## 조건 바꾸기
`config.json` 파일을 열어서 날짜(`date`, YYYYMMDD), 출발역(`dep`)/도착역(`arr`), 목표 출발시각(`dep_time`, HHMMSS)을 직접 수정하면 됩니다. 코드는 건드릴 필요 없습니다.

### 열차번호까지 구분하기 (선택)
각 목표(target)에 `train_no`를 추가하면, 시각이 같아도 지정한 열차번호가 아니면 "좌석있음"으로 인정하지 않습니다.
```json
{ "dep_time": "104100", "label": "9/27 익산→동탄 10:41", "train_no": "612" }
```
연결(결합) 운행되어 열차번호가 2개인 경우처럼 여러 번호 중 하나만 맞아도 되면 배열로 적습니다.
```json
{ "dep_time": "093200", "label": "9/27 익산→천안아산 09:32", "train_no": ["506", "408"] }
```
`train_no`를 아예 안 적으면 기존처럼 시각만으로 확인합니다.

## 참고
- 실제 코레일 사이트/앱과 같은 방식(API)으로 통신하는 `korail2` 라이브러리를 사용합니다. 화면을 직접 긁어오는 방식이 아니라서 사이트 디자인이 바뀌어도 잘 안 깨집니다.
- 로그인 정보는 절대 파일에 평문으로 저장되지 않습니다 (`keyring` → Windows 자격 증명 관리자).
- 이 도구의 컴플라이언스(약관 관련) 설계 배경은 `.omc/plans/korail-cancellation-catcher.md` 문서를 참고하세요.
